# RUMBLE 3D rebuild direction

The 2.5D prototype remains on main as a reversible checkpoint. The next visual prototype returns to Babylon.js and continues from the last stable 3D commit, but the old primitive-bear direction is retired.

Core goals:
- intentional stylized humanoid silhouette, not a placeholder animal
- guard stance, weight shift, anticipation and follow-through
- one opponent and one compact arena
- light / heavy / dodge combat feedback before feature expansion
- hit-stop, camera impulse and impact effects as first-class systems

No multiplayer, backend, progression, store, or unrelated feature expansion in this rebuild branch.

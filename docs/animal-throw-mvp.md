# Animal Throw MVP

This branch pivots RUMBLE from humanoid boxing to an animal object-throwing brawl.

Player loop: move -> approach an object -> grab -> auto-aim at rival -> throw -> dodge retaliation.

The first three object archetypes deliberately cover speed, mass and area denial:
- rock: fast, light hit
- crate: slower, heavy knockback
- bomb: timed area blast and respawn

The next quality gate is not feature count. It is whether one successful throw feels readable, funny and satisfying on a phone.
